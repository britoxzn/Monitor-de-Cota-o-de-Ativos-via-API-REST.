# Monitor de Câmbio em Tempo Real 📈

Aplicação desenvolvida em Python para monitoramento automatizado das cotações de Dólar e Euro em relação ao Real, utilizando consumo de API externa.

## 🛠️ Tecnologias e Conceitos
- **Linguagem:** Python.
- **Biblioteca:** `requests` para consumo de APIs REST.
- **JSON:** Manipulação de objetos de dados para extração de valores.
- **Automação:** Sistema de atualização periódica com tratamento de exceções.

## 🚀 Por que este projeto é relevante?
Este projeto demonstra minha capacidade de integrar sistemas com serviços externos e tratar dados dinâmicos, uma competência essencial para o desenvolvimento de aplicações modernas e integrações financeiras.
